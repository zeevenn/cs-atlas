## MySQL

存储与索引、查询优化、事务与锁，以及主备与运维。

### [MySQL 是怎样运行的](/mysql-how-it-works/)

教材 · 第 0–26 章

### [MySQL 实战 45 讲](/geektime-mysql-shizhan-45/)

围绕实际问题理解索引、锁、日志与主备。适合已有 SQL 使用经验，希望理解查询性能和日常运维问题的读者。
