## 1.1 数据库、数据库管理系统与 SQL

以保存公司的人事信息为例，先区分三个概念：

| 概念                   | 含义                     | 在例子中对应什么                             |
| ---------------------- | ------------------------ | -------------------------------------------- |
| 数据库（DB）           | 按一定结构保存的数据集合 | 人事数据库，包含员工、部门等表               |
| 数据库管理系统（DBMS） | 管理数据库的软件         | MySQL Server，负责存储、查询、权限和并发访问 |
| SQL                    | 操作关系型数据库的语言   | 用来建表、录入员工、查询部门人数的语句       |

应用或命令行客户端将 SQL 发给 MySQL Server，由服务器处理并返回结果。一个服务器可以管理多个数据库，一个数据库可以包含多张表。[MySQL 官方介绍](https://dev.mysql.com/doc/refman/8.4/en/what-is-mysql.html)

## 1.2 关系模型与查询结果

关系型数据库用表组织数据。员工表中，每行表示一名员工，姓名、薪资、入职日期等列描述员工的属性。

员工姓名可能重复，因此用主键 `id` 标识员工。部门也有自己的表和主键，员工表中的 `department_id` 保存所属部门的编号。例如，员工的部门编号为 `1`，就可以关联到部门表中编号为 `1` 的记录，而不必在每条员工记录里重复保存部门名称。

这种拆分让两张表分别维护各自的信息；需要同时展示员工姓名和部门名称时，再通过多表查询组合数据。

**查询生成的是结果集，不会因为查询而修改原表。** SQL 描述要取哪些数据，具体怎样查找由数据库决定；需要确定结果顺序时，必须使用 `ORDER BY`。[SELECT 语法](https://dev.mysql.com/doc/refman/8.4/en/select.html)
