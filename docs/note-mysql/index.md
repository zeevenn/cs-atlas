## 基础篇

按章节顺序学习；SQL 章建立员工、部门两张表，后续章节复用同一组数据。基础篇按 MySQL 8.4 / InnoDB 整理，涉及旧版本差异时另行说明；基础速查用于学完后查写法。

| 章节                                               | 阅读作用                                                       |
| -------------------------------------------------- | -------------------------------------------------------------- |
| [1. MySQL 概述](01-basics/01-overview.md)          | 分清数据库、数据库管理系统与 SQL，建立表、键和关系的基本认识。 |
| [2. SQL](01-basics/02-sql.md)                      | 用一组统一数据学习建表、写入、查询、分组、分页与权限控制。     |
| [3. 函数](01-basics/03-functions.md)               | 掌握字符串、数值、日期和条件处理的常见用法及边界。             |
| [4. 约束](01-basics/04-constraints.md)             | 用员工数据理解约束的作用、校验失败与外键行为。                 |
| [5. 多表查询](01-basics/05-multi-table-queries.md) | 理解连接后的行数、空部门统计与子查询的使用条件。               |
| [6. 事务](01-basics/06-transactions.md)            | 理解提交与回滚，通过两个连接观察隔离级别的差异。               |
| [MySQL 基础速查](01-basics/07-cheatsheet.md)       | 按操作查常用语法、函数和易错点。                               |
