## 数据库

### [数据库中的数据结构](/topics/database-data-structures)

从“数据库如何存储和查找一条记录”出发，学习记录与数据页、B+ 树、哈希表，以及 Buffer Pool 中的链表。当前选读来自《MySQL 是怎样运行的》和《MySQL 实战 45 讲》。

- **适合谁**：会基本 SQL，希望理解索引与存储原理的读者。
- **学习目标**：把抽象的数据结构与数据库中的查询、更新和缓存行为对应起来。
- **阅读方式**：按专题顺序选读，无需先读完两套资料。
